# 会话相关接口

> 源文件：`agentScope/src/agentscope/app/_router/_session.py`、`_chat.py`

## 接口列表

| 方法 | 路径 | 作用 | 依赖函数 |
|---|---|---|---|
| POST | `/sessions/` | 创建会话 | `get_current_user_id` |
| GET | `/sessions/` | 列出会话 | `get_current_user_id` |
| GET | `/sessions/{id}` | 获取会话详情 | `get_current_user_id` |
| PUT | `/sessions/{id}` | 更新会话 | `get_current_user_id` |
| DELETE | `/sessions/{id}` | 删除会话 | `get_current_user_id` |
| GET | `/sessions/{id}/status` | 获取会话状态 | `get_current_user_id` |
| GET | `/sessions/{id}/events` | SSE 事件流 | `get_current_user_id` |
| GET | `/sessions/{id}/messages` | 获取会话消息 | `get_current_user_id` |
| POST | `/sessions/{id}/interrupt` | 中断会话 | `get_current_user_id` |
| POST | `/chat` | 发送消息 | `get_current_user_id` |

所有接口均通过 `Depends(get_current_user_id)` 依赖函数自动注入 user_id，实际执行的是 `_platform_get_user_id`（从 JWT token 的 `sub` 字段提取）。

## 数据隔离链路

```
请求 Authorization: Bearer <JWT>
    ↓
AuthMiddleware 解码 JWT → request.state.user = {"sub": "用户ID", ...}
    ↓
_platform_get_user_id(request) → 返回 "用户ID"
    ↓
路由函数拿到 user_id 参数
    ↓
storage.list_sessions(user_id, agent_id)
    ↓
SQL: SELECT * FROM sessions WHERE user_id = ? AND agent_id = ?
```

## Storage 层隔离方式

| 方法 | SQL 层隔离 | Python 层校验 |
|---|---|---|
| `upsert_session` | 创建时绑定 user_id | — |
| `list_sessions` | ✅ `WHERE user_id = ?` | — |
| `list_sessions_by_schedule` | ✅ `WHERE user_id = ?` | — |
| `list_sessions_by_channel` | ✅ `WHERE user_id = ?` | — |
| `get_session` | ❌ 按 session_id 查 | ✅ 查出后校验 `row.user_id != user_id` |
| `delete_session` | ✅ `WHERE user_id = ?` | — |

## sessions 表结构

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | String(36) | 主键 |
| `user_id` | String | NOT NULL，有索引 |
| `agent_id` | String | NOT NULL，有索引 |
| `source` | String | 来源（user/schedule/channel） |
| `config` | JSON | 会话配置 |
| `state` | JSON | 智能体状态 |
| `created_at` | DateTime | 创建时间 |
